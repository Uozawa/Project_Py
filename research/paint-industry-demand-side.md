# 塗料業界 調査レポート（需要側フォーカス）

> 目的: 廃棄物と需要側（塗料メーカー等）が必要とする原材料をマッチングさせるための、需要側に関する基礎情報を整理する。
> 対象: 日本国内の塗料業界（必要に応じてグローバル動向を補足）。
> 最終更新: 2026-05-13

---

## 1. 業界スナップショット

| 指標 | 数値・概要 |
| --- | --- |
| 国内塗料出荷額（2023） | 約 **1兆3,351億円** |
| 国内塗料出荷量（2024年度見込み） | 約 **123万7千トン**（前年度比 -3.8%） |
| 国内塗料需要予測（2025年度） | 約 **124万8千トン**（前年度比 +0.9%） |
| 日本市場規模（2024、USD） | 約 **129億米ドル** |
| 日本市場成長率（2025-2033 CAGR） | 約 **5.08%** |
| 主要4社の国内シェア | 合計で **3割超** |

出典: 日本塗料工業会 (JPMA)、業界動向サーチ、塗料報知、IMARC Group。

### 業界構造の特徴

- **B2Bが中心**: 出荷量の大半は建築・自動車・工業向け（B2B）であり、DIY/家庭用は少数。
- **大量の化学品インプット**: 樹脂・顔料・溶剤・添加剤など多種類の化学原料を年間100万トン超の規模で消費。
- **環境規制の強化**: VOC規制・脱炭素対応のため、水性化／粉体化／バイオマス由来原料への転換が継続中。
- **マッチング機会の構造的存在**: 大量・継続的・規格品ベースの調達であるため、安定供給可能な代替原料（廃棄物・副産物由来）にニーズが生まれやすい。

### 2.2 用途別セグメント（需要先）

塗料の用途は大きく以下に区分される。マッチング対象を考えるうえで、用途ごとに**性能要求・規制水準・コスト感度**が異なる点に注意。

| 用途 | 主な需要先 | 性能要求の特徴 |
| --- | --- | --- |
| **建築用** | 建材メーカー、ゼネコン、塗装業者 | 耐候性、意匠性、コスト重視。VOC規制・F☆☆☆☆等。 |
| **自動車用** | 完成車メーカー、補修市場 | 仕上がり品質・耐候性が最優先。配合は高度に規格化。 |
| **工業用（金属／プラ）** | 家電、機械、金属加工 | 防錆、密着性、生産性。粉体・水性化が進行。 |
| **構造物用（重防食）** | 鋼橋、プラント、タンク | 長期耐久・防錆。Zn系・エポキシ系が主流。 |
| **船舶用** | 造船所、海運 | 防汚（生物付着防止）、耐塩水性。 |
| **木工用／家庭用** | 家具、DIY | 意匠性、低臭・水性化進行。 |

## 3. 塗料を構成する原材料（=需要側が消費するもの）

塗料は基本的に **4成分** から構成される。マッチング時はこの粒度で「何を供給できるか／何を求めているか」を擦り合わせる必要がある。

### 3.1 樹脂（バインダー）

塗膜の骨格。塗料の性能を最も大きく左右する。

| 樹脂種類 | 主な用途 | 廃棄物・再生材代替の可能性 |
| --- | --- | --- |
| アクリル | 建築外装、自動車上塗り、汎用 | 再生MMA（三菱ケミカルが植物由来MMA開発／PMMAケミカルリサイクル） |
| エポキシ | 重防食、プライマー、床、缶内面 | リグニン変性フェノール樹脂など部分代替検討あり |
| ポリウレタン | 自動車、木工、上塗り | バイオマスポリオール採用事例 |
| アルキド | 一般工業、汎用 | 植物油由来であり元々半バイオ系 |
| フッ素 | 高耐候・高耐久 | 代替困難領域 |
| メラミン／ポリエステル | 自動車、家電（焼付） | バイオマス由来原料は研究段階 |
| フェノール | プライマー、缶用 | リグニン変性（住友ベークライト商業化） |

### 3.2 顔料

| 種類 | 代表物質 | 役割 |
| --- | --- | --- |
| 白色顔料 | **酸化チタン（TiO₂）**、酸化亜鉛 | 着色・隠蔽の主役 |
| 黒色顔料 | **カーボンブラック** | 黒色、UV吸収 |
| 有色顔料 | 有機・無機顔料各種 | 色相 |
| **体質顔料** | **炭酸カルシウム、タルク、カオリン、シリカ、硫酸バリウム、水酸化アルミニウム** | 増量、流動調整、強度、光沢調整、密着性向上 |
| 防錆顔料 | リン酸亜鉛系等 | 防食 |

> **マッチング観点**: 体質顔料（炭酸カルシウム、タルク等）は **着色力よりも増量・補強が目的** であり、純度や色調の許容幅が比較的広い。鉱物系副産物（フライアッシュ・スラグ・建材端材由来微粉）が代替候補となり得る領域。

### 3.3 溶剤（溶媒）

- **有機溶剤系**: トルエン、キシレン、酢酸エチル、MEK、IPA等。VOC規制で減少傾向。
- **水系**: 水を主溶媒とし、近年急成長。
- **無溶剤系**: 粉体塗料、UV硬化等。

> **マッチング観点**: 再生溶剤（廃シンナーの精製再利用）は既に一部商業化（NCC他）。「との粉」を使った廃シンナー回収・再利用例あり。

### 3.4 添加剤

分散剤、消泡剤、レオロジー調整剤、硬化剤、UV吸収剤、防腐剤等。少量だが高機能、種類が極めて多い。
> **マッチング観点**: 量は少なく規格要求が厳しいため、廃棄物由来の代替は難易度が高い。

## 4. サーキュラーエコノミー／再生材料利用の現状

需要側（塗料メーカー）における廃棄物・副産物・再生原料の受け入れ動向。

### 4.1 進んでいる領域

- **廃塗料 → セメント原料**: 水性塗料の固液分離後、セメント原料化や燃料化が実用化。
- **廃シンナー（有機溶剤） → 再生シンナー**: 蒸留精製で再利用。NCCなどがリサイクルシステムを商業化。
- **バイオマス樹脂**: リグニン変性フェノール樹脂（住友ベークライト）、植物由来MMA（三菱ケミカル, 2026商業適用目標）、UV硬化バイオマス10–20%品（日本加工）。
- **リサイクル可能塗料**: 熱可塑性／可逆架橋設計で塗膜ごとマテリアルリサイクル（自動車バンパー用PPベース、トヨタ・VW等で工場内クローズドループ）。
- **古衣料 → 自動車用防音材**: 日本特殊塗料がユニクロ回収衣料からマテリアルリサイクル。

### 4.2 メーカー側の調達ポリシー

- **日本ペイントHD**: 「調達方針」を公開、ESGアジェンダで原材料の脱炭素化を推進。
- **関西ペイント**: 「グリーン調達」をサステナビリティ柱の一つに位置付け、サプライヤーとのCO₂削減協働を明示、2050年カーボンニュートラル目標。

### 4.3 規制上の留意

- **溶剤塗料の廃棄物は「特別管理産業廃棄物」**に該当する場合がある。
- **ハロゲン・フッ素含有** はセメントリサイクル時の忌避物質となるケースがあり、廃棄物→塗料原料化（あるいは逆方向）の流れでも成分情報の正確な把握が必須。
- **VOC・PRTR・化審法**等の規制適合は需要側が必ず確認する。

## 5. 廃棄物 → 塗料原料候補のマッピング（マッチング仮説）

需要側が「使えるかもしれない」と判断する典型的な変換パスを以下に整理する。

| 廃棄物・副産物の例 | 想定される代替先（塗料原料） | 検討すべき制約 |
| --- | --- | --- |
| 廃プラスチック（PMMA, PET, PP等） | 樹脂モノマー（ケミカルリサイクル経由） | 単量体への分解純度、色相、ハロゲン混入 |
| 廃食用油・植物油残渣 | アルキド樹脂用脂肪酸 | 不純物、酸価、色 |
| リグニン（製紙副産物） | フェノール樹脂代替、添加剤 | 反応性、色、ロット安定性 |
| フライアッシュ／クリンカアッシュ | 体質顔料（増量材） | 粒径、未燃カーボン、重金属 |
| 高炉スラグ・各種スラグ微粉 | 体質顔料 | 粒度、化学組成 |
| 建材端材・石材スラッジ | 炭酸カルシウム代替体質顔料 | 不純物、色 |
| 廃シンナー・洗浄溶剤 | 再生シンナー | 含水率、不純物、ハロゲン |
| カーボンブラック（タイヤ熱分解 rCB） | 黒色顔料／導電性付与剤 | 粒径、灰分、官能基 |
| 古紙・繊維くず | 添加剤（増粘・補強） | 形状均一性、衛生 |
| 廃塗料そのもの | 再生塗料（建築下塗り等） | 色管理、規格適合 |

## 6. マッチングに必要な「需要側」情報項目（データスキーマ案）

ここが本タスクのコアです。塗料メーカー側から引き出すべき情報を **「マッチング用データ項目」** として体系化しました。

### 6.1 メーカー基本情報

- 企業名／事業所所在地／受入可能拠点
- 主力セグメント（建築／自動車／工業／重防食／船舶／木工 等）
- 主力樹脂系（アクリル／エポキシ／ウレタン…）
- 環境・調達ポリシー（グリーン調達基準、再生材使用目標値）

### 6.2 求める原料の仕様（=需要プロファイル）

| カテゴリ | 必要項目 |
| --- | --- |
| **原料カテゴリ** | 樹脂 / 顔料（白／黒／有色／体質／防錆） / 溶剤 / 添加剤 / フィラー |
| **化学組成** | 主成分、不純物許容上限、ハロゲン・重金属・S・N 含有量 |
| **物性** | 粒径分布、比重、吸油量、粘度、軟化点、酸価／水酸基価、Tg、屈折率 など（カテゴリ別に異なる） |
| **色・外観** | 色相（L\*a\*b\*）、白色度、隠蔽力 |
| **品質安定性** | ロット間ばらつき許容範囲、含水率、保管安定性 |
| **規制適合** | RoHS / REACH / 化審法 / PRTR / VOC / 食品接触 / F☆☆☆☆ / 海外規制 |
| **数量** | 月次／年次必要量、最低発注ロット、需要変動パターン |
| **価格** | 既存原料に対する許容価格レンジ |
| **物流** | 受入形態（バルク／フレコン／ドラム）、納入頻度、受入可能拠点 |
| **トレーサビリティ** | 由来証明、Mass Balance方式の可否、第三者認証（ISCC PLUS等） |
| **CO₂・LCA** | カーボンフットプリント開示要否、Scope3算定基準 |
| **試験プロセス** | サンプル量、評価期間、量産採用までのリードタイム |

### 6.3 採用プロセスの段階情報

塗料メーカーは新規原料を一括採用しない。**段階ゲート** が存在する点をマッチング側も理解する必要がある。

1. **書類審査（SDS／成分／規制適合）**
2. **少量サンプル評価**（数百g〜数kg）
3. **ラボ配合試験**（既存配合への置換試験）
4. **パイロット試作**
5. **長期安定性試験**（耐候性、貯蔵安定性）
6. **量産トライアル**
7. **本採用（複数年契約・ロット保証）**

リードタイムは通常 **6か月〜2年以上**。マッチングプラットフォームは「どの段階の対話か」を可視化すべき。

## 7. 廃棄物側（供給側）に対して求められる情報（鏡像）

参考までに、需要側が満足するためには供給側から以下が出てくる必要があります。

- 物質名／組成分析データ（成分、不純物、含水率）
- 発生量・発生頻度・継続性の見通し
- 形態（粉体／液体／塊状）と粒度
- 由来工程（コンタミ・規制物質の混入可能性）
- 規制上の区分（一般廃棄物／産廃／特管産廃）
- 法的処理ステータス（自社処分／処理委託／資源化登録）
- 保管・輸送条件、ロット単位
- 提示価格（または逆有償）
- サンプル提供可否

## 8. 想定リスクと留意点

- **規格安定性リスク**: 廃棄物由来は組成変動が大きく、塗料メーカーの品質基準を満たしにくい。**規格化・選別・前処理** の工程設計がマッチング成否を左右する。
- **法規制リスク**: 廃棄物処理法、化審法、REACH等への適合確認は必須。「廃棄物」のステータスで譲渡できるか、再資源化登録が必要かを案件ごとに確認。
- **責任の所在**: 不良品発生時の品質責任、リコール時の費用負担などをマッチング契約で明確化。
- **競争上の機微情報**: 塗料配合は企業秘密。需要側は具体的な「現使用原料」を開示したがらないため、マッチング側は **仕様ベース**（性能・許容範囲）で対話を設計する必要がある。

## 9. 次のアクション（提案）

1. **需要側ヒアリング設計**: 上記 6.2 のデータ項目をベースに、メーカー向け一次ヒアリングフォーマットを作成する。
2. **優先ターゲットの絞り込み**: マッチング難易度の低い領域（体質顔料・再生溶剤・バイオマス樹脂）から着手する仮説を立てる。
3. **既存マッチングプラットフォームの調査**: 愛知県「循環資源事業者マッチングシステム」など先行事例の機能・運営方式を分析。
4. **供給側プロファイル設計（鏡像）**: 7. を発展させ、廃棄物側のデータスキーマを別ドキュメントとして整備。
5. **法規制チェックリスト整備**: 廃掃法・化審法・グリーン購入法等のフィルタを共通仕様化。
