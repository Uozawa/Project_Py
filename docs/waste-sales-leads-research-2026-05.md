# 廃棄物・営業ネタ調査レポート（2026年5月時点）
## 「現在の社会情勢」から「新しい廃棄物の発生源」を読む

> 対象: 中間処理業者の営業職／スコープ: 化学系・特管産廃＋資源リサイクル系（横断的）／エリア: 全国横断
> 作成基準日: 2026年5月20日

---

## 0. このレポートの使い方・注意

- 目的は「**社会情勢 → 新しい廃棄物が発生する場所 → 想定顧客**」を地図化し、営業仮説の出発点にすること。
- 記載は**公開情報に基づく仮説**であり、確定情報ではない。個社の機密・未公表案件には踏み込まない。
- 使い方: ①第2章で「今、世の中で何が起きているか」を掴む → ②第3章の発生源仮説マップで「誰に何を持っていくか」を選ぶ → ③第4章で自社主力に当てはめて優先順位を決める → ④第5章のソースで継続ウォッチ。

### トップ仮説（先に結論）
1. **半導体国内回帰**（熊本JASM・千歳Rapidus等）に伴う**濃厚廃酸・廃アルカリ・汚泥（特管産廃）**の新規・増加。化学系の最右翼。
2. **AIデータセンター建設ラッシュ＋ハード更新**による**E-waste・使用済み蓄電池・冷却液**。資源リサイクル系の追い風。
3. **電池リサイクル義務化（FY2026〜）とEV電池の本格廃棄**による**LIB・ブラックマス**の発生源拡大。
4. **物価高倒産・廃業の増加**による**設備・在庫・廃液の一括処分スポット**。短期で刈り取りやすい。

## 2. マクロ前提：2026年5月の社会情勢（営業ネタの源泉）

各トピックを「**何が起きているか**」と「**なぜ廃棄物に効くか**」で整理する。

### (A) 地政学：中東発の原油・ナフサ供給ショック
- **何が起きているか**: 2026年2月の米・イスラエルによるイラン攻撃以降、日本の原油輸入は一時約9割減、直近も紛争前比6〜7割減で推移との分析。ホルムズ海峡の航行は未正常化で、原油・ナフサの供給不足懸念が継続。為替は対ドル157円台の円安。
- **なぜ廃棄物に効くか**: ナフサは石化・樹脂原料の起点。供給不安・原料切替は、**石化/化学/樹脂メーカーの操業調整・歩留り変動・在庫劣化品・不良品廃棄**を誘発しやすい。コスト高は後述の倒産・廃業（F）にも波及。
- 出典: [NRI（オイルショック比較）](https://www.nri.com/jp/media/column/kiuchi/20260507_2.html) / [帝国データバンク（原油高騰の影響）](https://www.tdb.co.jp/report/economic/20260406-tdbreview-no45/) / [Bloomberg（5/11市況）](https://www.bloomberg.com/jp/news/articles/2026-05-11/TEUCOYKGIFPE00) / [資源エネルギー庁（石油等への対応）](https://www.enecho.meti.go.jp/category/others/energysecurity/index.html) / [内閣府（月例トピック）](https://www5.cao.go.jp/keizai3/monthly_topics/2026/0327/topics_082.pdf)

### (B) 経済安保：半導体の国内回帰
- **何が起きているか**: 千歳（北海道）でRapidusが2nm量産準備（2027年量産目標）、熊本でJASM（TSMC子会社）が稼働＋第2工場が進行。装置・部素材投資は過去最高水準、政府は2030年に国内半導体生産15兆円を目標。
- **なぜ廃棄物に効くか**: 半導体前工程は薬液を大量使用。**フッ酸系・硝酸系・硫酸系・塩酸系・リン酸系などの濃厚廃酸、廃アルカリ、研磨スラリー、洗浄廃液、排水処理汚泥**が継続発生（**特別管理産業廃棄物**を含む）。工場新設は建設廃棄物も生む。
- 出典: [東京エレクトロン TELESCOPE（2026年の半導体工場事情）](https://www.tel.co.jp/museum/magazine/report/202604_02/) / [経産省 半導体・デジタル産業戦略](https://www.meti.go.jp/policy/mono_info_service/joho/conference/semicon_digital/0014/handeji14-3.pdf) / [JETRO 世界投資報告](https://www.jetro.go.jp/world/gtir/2025/ch2/sec2/sub2.html) / [SEAJ 需要予測](https://www.seaj.or.jp/file/jan2026seajforecastforpress_j.pdf)

### (C) AIデータセンター（DC）建設ラッシュ
- **何が起きているか**: 生成AIで電力・計算需要が急増。ソフトバンクが苫小牧で国内最大級300MW級を建設中（2026年度第1期稼働）、さくらインターネット石狩でNVIDIA最新GPUを大量配備、京都・舞鶴等でも大型投資。建設ラッシュは全国に拡大。
- **なぜ廃棄物に効くか**: ①建設フェーズ＝**建設混合廃棄物・がれき・残土・梱包材**、②稼働後＝GPU/サーバーの更新サイクルで**E-waste（基板・サーバー）**、③**UPS用の鉛/リチウム蓄電池**、④液浸冷却の普及で**廃冷却液（廃油類）**。E-wasteはハード更新が常態のDCで構造的に増える。
- 出典: [日経BOOK（DC業界地図2026）](https://bookplus.nikkei.com/atcl/column/020500658/020500006/) / [日経xTECH（建設ラッシュは全国に）](https://xtech.nikkei.com/atcl/nxt/mag/nc/18/122500396/122500010/) / [AIデータセンター建設ラッシュの全貌（note）](https://note.com/shin_tigerjet/n/nedec1f081d1a) / [E-wasteとは（Pure Storage）](https://www.purestorage.com/jp/knowledge/what-is-e-waste.html)

### (D) リサイクル法制化：太陽光パネル／電池
- **何が起きているか**: 2026年4月3日、「太陽電池廃棄物の再資源化等の推進に関する法律案」を閣議決定（成立すれば2027年末にも施行見込）。多量排出のメガソーラー事業者等にリサイクルを義務付け。排出量は2030年代後半に顕著増、**最大年50万t**の見込み。あわせてモバイルバッテリー・スマホ等の**リチウムイオン電池の回収・リサイクル義務化（改正資源有効利用促進法、FY2026施行）**。
- **なぜ廃棄物に効くか**: ①使用済み**太陽光パネル（ガラス・廃プラ・金属・鉛等の有害含む）・パワコン・架台金属**、②**使用済みLIB**。法制化＝排出ルートと処理需要が制度的に立ち上がる。早期は「仕込み」、本格化は2030年代。
- 出典: [METIプレス（法案閣議決定 2026/4/3）](https://www.meti.go.jp/press/2026/04/20260403002/20260403002.html) / [環境省 リサイクル制度小委資料](https://www.env.go.jp/content/000378443.pdf) / [日経（モバイル電池回収義務化）](https://www.nikkei.com/article/DGXZQOUA128QY0S5A810C2000000/) / [SMART ENERGY WEEK（パネル大量廃棄）](https://www.wsew.jp/hub/ja-jp/blog/article_45.html)

### (E) EV・車載電池リサイクルの本格化
- **何が起きているか**: 中国で主流のLFP系電池の廃棄が2026年以降急増見込。国内では**ブラックマス**（破砕・焼成で得る金属濃縮中間物）の処理が拡大。JX金属サーキュラーが敦賀で2027年量産検証、住友金属鉱山が国内精製、松田産業×太平洋セメントが「電池to電池」。国の蓄電池関連設備投資認定は8件・総額1,167億円（最大助成444億円）。
- **なぜ廃棄物に効くか**: **使用済み車載LIB・モバイル電池・ブラックマス**の中間処理・前処理（破砕・選別・無害化）の需要拡大。資源リサイクル系に直結。
- 出典: [日経（住友金属鉱山 EV電池リサイクル）](https://www.nikkei.com/article/DGXZQOUC1179Y0R11C24A0000000/) / [松田産業 LIBリサイクル](https://service.matsuda-sangyo.co.jp/greenbusiness/disposal/lib/) / [経産省 蓄電池産業戦略](https://www.meti.go.jp/policy/mono_info_service/joho/conference/battery_strategy2/shiryo03.pdf) / [蓄電池リユース・リサイクル最新動向](https://www.enegaeru.com/latesttrendsinbatteryreuse-recycling2025)

### (F) 景気：物価高倒産・廃業の増加
- **何が起きているか**: 2025年度の全国企業倒産は1万425件（2年連続1万件超）。物価高倒産は963件で過去最多。業種別は建設業247件、小売227件、製造業177件。2026年4月の物価高倒産は前年同月比+51.7%。原油高（A）由来の運輸・原材料コスト、人手不足、円安が収益を圧迫。
- **なぜ廃棄物に効くか**: 廃業・倒産・撤退は**在庫・原材料・設備・廃液・什器の一括処分**を生む**スポット案件**の宝庫。製造業・建設業の比率が高く、化学系廃液を伴うケースもある。リードタイムが短く刈り取りやすい。
- 出典: [帝国データバンク 倒産集計2025年度報](https://www.tdb.co.jp/report/bankruptcy/aggregation/20260408-bankruptfy2025/) / [東京商工リサーチ（物価高倒産 2026/4）](https://www.tsr-net.co.jp/data/detail/1202840_1527.html) / [アラームボックス（業種別倒産予測）](https://prtimes.jp/main/html/rd/p/000000101.000024095.html)

### (G) 大型施設・建築物の解体
- **何が起きているか**: 大阪・関西万博の閉幕後、会場の建築物（大屋根リング等）の大半が産業廃棄物化し、「持続可能性」理念とのギャップが指摘。空き家解体には自治体補助が広がる。
- **なぜ廃棄物に効くか**: 解体は**建設混合廃棄物・がれき・木くず・廃石膏ボード**を一時に大量発生させる。跡地再開発もパイプライン化。
- 出典: [神戸新聞（万博 建築資材の大半が産廃に）](https://www.kobe-np.co.jp/news/culture/202604/0020281734.shtml) / [国交省 建設リサイクル推進計画](https://www.mlit.go.jp/sogoseisaku/region/recycle/d03project/d0301/page_030103program2.htm)

## 4. 御社主力への当てはめ（優先順位）

スコープ（**化学系・特管産廃＋資源リサイクル系＋横断／全国**）に最適化した優先順位。

- **最優先① 半導体工場の濃厚廃酸・廃アルカリ・汚泥（特管産廃）**
  - 理由: 化学系の本丸。稼働中・拡張中で発生が継続。熊本・北海道に加え、広島・三重・山形等の半導体/部素材集積も候補。
  - 当て先: JASM・Rapidus本体に加え、**到達しやすい協力企業・部素材/薬液/装置メーカー・排水処理委託の二次先**から。
- **最優先② DC/EV/モバイル由来の使用済み電池・E-waste・ブラックマス**
  - 理由: 資源リサイクル系の追い風（法制化＋市場拡大）。中間処理（破砕・選別・前処理）の出番。
  - 当て先: DC運営・回収事業者・電池/自動車メーカー・家電量販の回収網。
- **準優先③ 廃業・倒産スポット案件**
  - 理由: 横断・短期で刈り取り可。製造業/建設業比率が高い。
  - 当て先: 整理回収・M&A仲介・不動産・解体業者との連携で情報を取りに行く。
- **仕込み④ 太陽光パネル**
  - 理由: 本格排出は2030年代後半。今は制度ウォッチ＋メガソーラー/EPC/解体とのネットワーク構築フェーズ。
